JamAI apt repository

Write music in ABC notation, hear it, publish it, and let an AI agent work in your MuseScore score. Source and documentation.

Install on Debian or Ubuntu

curl -fsSL https://apt.gmusicassembly.com/setup.sh | sudo bash
sudo apt install jamai

The first line runs once: it adds this repository and its signing key. After that, sudo apt upgrade brings each new version.

Or by hand, step by step

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://apt.gmusicassembly.com/jamai.gpg | sudo tee /etc/apt/keyrings/jamai.gpg > /dev/null
echo "deb [signed-by=/etc/apt/keyrings/jamai.gpg] https://apt.gmusicassembly.com stable main" | sudo tee /etc/apt/sources.list.d/jamai.list
sudo apt update && sudo apt install jamai
